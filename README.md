A deterministic program that writes one funny single-line one-star review from a house cat about its human. The cat's complaint is specific — a bowl that is only half full — and the review ends with the cat escalating the matter to the only authority in the house who pretends to listen.

> One star. My human refills my bowl only when it is half full, which is cat for empty. I have filed a formal complaint with the dog.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The entry line is 131 characters long, and the output is deterministic: every run writes the exact same line to `entry.txt`.
